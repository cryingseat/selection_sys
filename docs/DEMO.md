# 演示脚本

> 演示环境默认 `app.enforce-time-window=false`，可以在同一天内手动推进全部阶段。  
> 生产环境请改为 `true`，并确保批次各阶段时间配置正确。

## 0. 启动

```bash
# 终端 1：MySQL 已启动，后端自动建表并写入演示数据
cd backend
java -jar target/selection-backend-1.0.0.jar

# 终端 2：前端
cd frontend
npm run dev
```

打开 `http://127.0.0.1:5173`。  
演示账号密码均为 `123456`：`admin`、`t1001`、`t2001`、`t3002`、`S2023001`、`S2023008` 等。

当前种子数据：

- 进行中批次：`2026年秋季实训室进组选拔`，状态 `INTENT_OPEN`；
- 历史批次：`2026年春季实训室进组选拔`，状态 `FINISHED`，含确认、候补递补、内部/跨室调剂、公示记录；
- 3 个实训室、6 位导师、14 名学生；
- 当前批次已有 7 份提交报名 + 1 份草稿，可直接演示导师端筛选与审核。

## 1. 公开页与登录

1. 打开首页，查看：
   - 当前批次、8 步流程（当前第 3 步“意向填报”高亮）；
   - 3 个实训室、导师、剩余名额；
   - 通知公告与选拔规则；
2. 点击“登录参与选拔”，使用 `S2023008 / 123456` 登录。

预期：进入学生工作台，显示“尚未提交报名”，可去填报。

## 2. 学生填报 3 个平行意向

1. 进入「意向填报」；
2. 从右侧选择：
   - 张明（智能感知与边缘计算实训室）
   - 王强（数据智能与知识工程实训室）
   - 陈晨（人机交互与数字媒体实训室）
3. 填写个人简介、技术基础、项目经历；
4. 调剂意愿选择“接受跨实训室调剂”；
5. 可勾选“明确拒绝的实训室”，观察系统会移除该室已选导师；
6. 点击“提交报名”，在确认弹层中确认。

预期：

- 提示提交成功；
- “平行意向清单”显示 3/3；
- 工作台“报名状态”变为“已提交”；
- 再次提交会更新原报名，不会产生重复记录。

> 用 `S2023013`（2024 级）登录尝试提交，会被“资格校验”拦截，提示不符合本批次年级要求。

## 6. 候补与分轮补录

1. 在面试阶段，用 `t3002`（刘洋）给郑可（S2023007）的意向设置“候补，顺位 1”；
2. 管理员推进到“分轮补录”；
3. 系统自动创建第一轮，进入「分轮补录」：
   - 点击“开放轮次”；
   - 点击“执行候补递补”，系统按顺位给郑可发拟录取；
4. 用 `S2023007` 登录，在「拟录取确认」或「补录填报」中确认；

6. 对应导师进入「补录管理」提交拟录取；

预期：

- 候补按顺位自动转拟录取；
- 补录阶段可重新填报最多 3 个意向；
- 结束轮次时未确认的拟录取自动标记逾期并释放；

## 7. 统筹调剂

1. 管理员推进到“统筹调剂”；
2. 进入「统筹调剂」：
   - 查看待调剂学生、调剂意愿、已填报实训室；
   - 点击“一键统筹调剂”；
3. 系统按优先级处理：
   - 第一优先级：学生填报过的实训室内部；
   - 第二优先级：跨实训室（需学生授权）；
   - 第三优先级：无余额/不接受调剂 → 谈话安置；
4. 可在待调剂学生行使用“手动调剂”选择目标导师，或“谈话安置”；
5. 查看调剂记录。

预期：

- 成功调剂的学生生成最终录取与调剂记录；
- 不接受调剂/无余额的学生生成谈话记录；
- 不会分配到学生明确拒绝的实训室；
- 导师/实训室名额仍受校验。

## 8. 公示与锁定

1. 管理员推进到“结果公示”；
2. 系统自动生成公示草稿（也可手动“生成公示草稿”）；
3. 进入「结果公示」：
   - 查看名单；
   - 点击“发布公示”；
4. 打开公开首页，底部出现“公示结果”表格；
5. 尝试修改任何录取操作，应被“公示锁定”拒绝；
6. 点击“结束并锁定”：
   - 公示状态变“已结束”；
   - 最终录取状态变“已锁定”；
   - 批次状态变“已完成”；
7. 如需更正：点击“撤回公示”，填写原因，系统回到调剂阶段并解锁；修改后重新生成/发布公示。

预期：公示发布后不可改；结束后锁定；撤回后可改，全程写入审计日志。

## 11. 重置演示数据

方式 A（推荐）：删除数据库后重启后端：

```sql
DROP DATABASE selection_sys;
```

后端启动时会自动 `createDatabaseIfNotExist` 并执行 `schema.sql` + `data.sql`。

方式 B：手动执行：

```bash
mysql -uroot -p < database/init.sql
```

> `data.sql` 使用 `INSERT IGNORE`，重复执行不会覆盖已存在记录；要恢复初始状态，请先删库/清表。

## 13. 演示提示

- 所有列表、统计、状态均来自后端接口，刷新页面不会丢失；
- 前端路由有角色守卫，学生无法直接访问 `/admin`；
- 导师端看不到学生其他平行意向的具体导师，只显示“另有 N 个”；
- 公示前，学生只能查看自己的结果，不能查看其他学生；
- 时间校验默认关闭是为了演示流畅，生产环境请打开。
